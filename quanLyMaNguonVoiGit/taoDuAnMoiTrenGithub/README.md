1. Ý nghĩa các câu lệnh Git đã sử dụng trong bài:

- git init: Khởi tạo một Local Git Repository mới trong thư mục dự án.
- git remote add origin <URL>: Kết nối Local Repository với Remote Repository trên GitHub.
- git add README.md: Đưa file README.md vào khu vực Staging Area (chỉ mục) để chuẩn bị cho việc lưu trữ.
- git commit -m "message": Lưu lại phiên bản thay đổi hiện tại của các file trong Staging Area kèm thông điệp mô tả chi tiết.
- git push -u origin main: Đẩy (tải) các commit từ nhánh main dưới Local Repository lên Remote Repository trên GitHub.
