Phần 1: Tiêu đề dùng Inline CSS

Đoạn văn này được đổi màu xanh lục/dương trực tiếp bằng thuộc tính style trong thẻ.

Phần 2: Tiêu đề dùng Internal CSS

Đoạn văn này được đổi màu tím bằng thẻ style nằm trong phần head.

Phần 3: Tiêu đề dùng External CSS

Đoạn văn này được đổi màu cam bằng file CSS liên kết bên ngoài (style.css).
